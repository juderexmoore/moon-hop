# Moon Hop

A family-built browser game: climb from the Meadow all the way to the Moon.
Every round, a family member added one new idea.

**Play:** open the GitHub Pages link for this repo, or open `index.html` in a browser.

## Controls

| Key | What it does |
|---|---|
| Arrows or A / D | Move |
| Space, Up or W | Jump (hold to jump higher) |
| F or J | Shoot |
| Ctrl + B | Cast the dog's spell |
| V | Switch dog spell |
| P or Esc | Pause |
| S (title screen) | Sandbox: build your own levels and characters |

High scores, levels and characters save in your own browser.

## Playing at home with saved files

Double-click `Play Moon Hop.bat` (Windows). It runs the game at http://localhost:8765/
and saves the leaderboard, levels and characters to `scores.json` and `sandbox.json` in this folder.
